# AlignLab

A reproducible playground for **LLM post-training**: supervised fine-tuning (SFT), parameter-efficient fine-tuning (LoRA/QLoRA), preference optimization (DPO), and evaluation.

> **Status:** Initial scaffold. Training and evaluation implementations are planned, not yet available.

## Quick start

Install [uv](https://docs.astral.sh/uv/), then:

```bash
uv sync
uv run pytest
uv run ruff check .
```

## Structure

- `configs/`: training configuration examples
- `src/alignlab/data/`: dataset preparation
- `src/alignlab/training/`: training pipelines
- `src/alignlab/evaluation/`: benchmark runners and metrics
- `src/alignlab/inference/`: generation and model serving
- `tests/`: automated checks

## Reproducibility

Pin dependencies with `uv lock` (generated by `uv sync`) and commit `uv.lock`. Record model revision, dataset revision, seed, and hardware for each experiment. Avoid mixing training and held-out evaluation examples.
